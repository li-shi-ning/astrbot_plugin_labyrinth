# 《Labyrinth 疯狂迷宫》规则调研

本插件实现的是 Ravensburger 1986 年的经典桌游《Das verrückte Labyrinth》
（英文 *The aMAZEing Labyrinth*，中文常称「疯狂迷宫」/「迷宫」）。

## 配件

| 配件 | 数量 |
| --- | --- |
| 棋盘格 | 7×7 = 49 |
| 固定牌（印在棋盘上，偶数行×偶数列） | 16 |
| 可移动牌 | 34（33 张在棋盘上 + 1 张手牌） |
| 宝藏卡 | 24 |
| 棋子 | 4（黄/红/蓝/绿，放在四角起点） |
| 推牌箭头 | 12（第 2/4/6 行与第 2/4/6 列各两个方向） |

## 牌型

rotation=0 时的出口（方向编号 0=上 1=右 2=下 3=左）：

| 牌型 | 出口 | 数量（可移动牌） |
| --- | --- | --- |
| `straight`（直路） | 上、下 | 12（无宝藏） |
| `corner`（拐角） | 上、右 | 10（无宝藏）+ 6（带宝藏） |
| `t-shape`（三通） | 上、右、下 | 6（带宝藏） |

固定牌：12 张三通（各带 1 个宝藏）+ 4 张拐角（四角，起点，无宝藏）。

> 经典版**没有**四向十字牌。

## 宝藏（24）

* 固定牌上 12 个：🪖 骑士头盔、🕯️ 烛台、⚔️ 剑、💎 宝石、🧰 宝箱、💍 戒指、
  🗺️ 藏宝图、🔑 钥匙、👑 王冠、⚗️ 瓶中幽灵、💰 金币袋、📖 书
* 可移动牌上 12 个：🐀 老鼠、🦇 蝙蝠、🦉 猫头鹰、🦎 蜥蜴、🕷️ 蜘蛛、🦋 飞蛾、
  🪲 圣甲虫、💀 骷髅、🐉 龙、👸 公主、🧙 女巫、👻 幽灵

> 对玩家展示统一用「emoji + 中文名」；emoji 表在 `src/tiles.py::TREASURE_EMOJI`。

> 宝藏 id 与 `assets/treasures/<id>.png` 一一对应，见 `scripts/build_assets.js`。

## 流程

1. **准备**：可移动牌洗混后随机铺满 33 个空格，剩 1 张做手牌；
   24 张宝藏卡洗混后平均发给玩家（2 人各 12、3 人各 8、4 人各 6），
   各自面朝下成一摞；棋子放在四角起点。
2. **回合**：
   1. **推牌**：把当前手牌插到 12 个箭头之一（第 2/4/6 行或列），
      对端被挤出的牌成为你的新手牌。**插入前可以任意旋转手牌**。
      - 不能把上一手刚推出的位置原路推回去。
      - 推出的那张牌立刻成为手牌，可以在**下一回合**从任意箭头插入。
   2. **移动**：沿通道任意走（也可以原地不动）。棋子可以重叠。
3. **推牌会带动整条线上的所有棋子**；被挤出棋盘的棋子放到**新插入的那格**。
4. **收集**：走到自己当前目标宝藏所在格即完成该目标，翻出下一张。
5. **胜负**：集齐自己的全部目标后，回到自己的起点格即获胜。

## 本插件的取舍

| 规则点 | 官方 | 本插件 |
| --- | --- | --- |
| 手牌旋转 | 插入前自由旋转 | 「迷宫 转」每次顺时针 90°，可多次 |
| 可达提示 | 玩家自己看 | 文本列出可达格子，避免误操作 |
| 当前目标 | 面朝下、自己看 | 私密按钮（`only_for`，只进本人输入框） |
| 美术素材 | 原版插画 | 内置 `assets/` PNG（由 `scripts/build_assets.js` 从 SVG 素材包生成） |
| 已收集宝藏 | 翻开放置 | 公开显示在牌桌摘要 |
